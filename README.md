# EasyCPTrans

EasyCPTrans 是一个面向 Windows 的轻量化、离线、方便快捷、好看好用的剪贴板工具。

它的目标是把“剪贴板历史”“快速复制粘贴”“标签筛选”“快捷键调用”做成一个流畅、低占用、可长期使用的桌面工具，并逐步扩展到划词翻译、OCR 翻译和剪贴板联动。

### 8. 快捷键与粘贴逻辑

- 默认全局唤出面板快捷键改为 `Ctrl + Shift + V`
- 全局数字快捷粘贴改为 `Win + Shift + F1 ~ F10`
- 队列粘贴快捷键改为 `Ctrl + Alt + V`
- `ctrl + Alt + V` 作为队列步进相关行为
- 快捷键录制不能只是字符串输入，必须是真正识别按键组合
- 录制时要检查是否被占用
- 录制时如果点击其他地方，要自动停止
- 需要把快捷键相关逻辑尽量放到后端处理，提高速度和稳定性
- `#1 ~ #10` 作为序号水印显示，不占正文内容

### 9. 队列粘贴

- 支持入队
- 每次按队列快捷键只出队一个
- 必须严格按照入队顺序粘贴
- 出队后，后续队列序号要自动前移
- 这一逻辑不能出现乱序或重复粘贴

### 10. 截图与图像内容

- 截图内容要能被稳定读取
- 图片类剪贴板内容要能正确显示与粘贴
- 截图写入和读取要尽量避免 `unexpected end of file` 一类错误
- 需要尽量提高截图识别与加载成功率

### 11. 窗口行为

- 窗口大小和位置需要持久化
- 退出时保存窗口状态，下次启动恢复
- 初始化窗口不能先在默认位置闪一下再跳走
- 窗口调整大小时不应误判为点击隐藏
- 调整窗口大小时，页面不要直接最小化或隐藏
- 窗口圆角略大一些
- 主内容底部和窗口底边需要尽量贴合

### 12. 数据与迁移

- 后续需要补 WebDAV 配置
- 需要支持数据库相关迁移
- 希望旧数据能够迁移过来
- 现阶段不强求多端同步，但保留后续扩展空间

## 后续计划

后续优先级大致如下：

划词翻译的实现（仅支持单词，短语）：
用户划词之后，使用快捷键alt+C；使用快捷键之后自动复制这个单词（复制之后会成为新的item，并自带#Word这个tag）同时后台进行检索翻译，随即弹出面板并等待翻译完成，完成后自动将这个item的内容替换为翻译内容（词典释义等），整体相当于将翻译后的内容弄到最新的剪切板了，由于历史剪切板的item都是卡片形式所以能够很好地用于展示查看。
翻译词典使用ECDICT的sqlite实现。
